Sidebar View 修正報告

日期：2026-09-12

已修改檔案

  • extension.js

修改內容

  1. 新增 sendTo(webviewView, type, data, id)，讓訊息可以明確送往指定的 Webview。
  2. 保留原本的 send() 作為相容包裝，仍可使用目前的全域 View。
  3. 調整 wirePanel() 內的請求回覆流程，改為使用目前請求所屬的 webviewView 傳送回覆。
  4. 避免兩個 Sidebar View 共用全域狀態時，回覆被送到最後綁定的 View。

  • webview/dist/panel.js
  • webview/dist/panel.js.map

驗證結果

  • npm test：17 項測試全數通過，0 失敗。
  • npm run build：建置成功。

範圍限制

本次修正處理的是「請求回覆可能被送到另一個 View」的問題。 背景 post() 流程仍使用單一 active View；若要完全隔離每個 View 的背景狀態，仍需另行拆分 per-View session/state。
