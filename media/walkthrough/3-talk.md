# パネルを開いて、頼む

- **送るのは Shift+Enter**（Enter は改行。設定 `chatgptBridge.requireModifierToSend` で入れ替えられます）
- `@` でファイルを名指しできます。編集画面で選んでから **⌥K** でも入ります
- 走っている間も打てます。後ろに並びます
- 止めたい時は、入力欄の上の停止

**モード（権限モード）は Shift+Tab で回せます。**

- `plan` … 読むだけ。段取りが決まったら、相手が `exit_plan_mode` で聞いてきます
- `edit` … 作業場の中は聞かずに書く（既定）
- `never` … 聞かない（隔離した作業場だけで）
